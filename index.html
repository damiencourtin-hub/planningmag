⬡ Sauvegarde GitHub — Multi-postes
💡 Comment ça fonctionne ?
Vos données et profils sont sauvegardés dans votre repo GitHub. Sur un nouveau poste, l'app les recharge automatiquement → vos profils apparaissent, entrez votre PIN, c'est tout.
Créer un token GitHub : github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) → New token → cochez repo → Générer → Copier
🔗 Connexion SharePoint
Paramètres SharePoint
Obtenir via : Azure Portal → App Registrations → votre app → API permissions → SharePoint.ReadWrite.All
Synchronisation manuelle
📤 Publier vers SP

📥 Charger depuis SP
Importe les données SharePoint dans l'application. Les données locales non sauvegardées seront perdues.
