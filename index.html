⬡ GitHub — Synchronisation multi-postes
Créer un token GitHub : github.com → Settings → Developer settings → Personal access tokens → Tokens (classic) → New token → cochez repo → Générer → Copier
🔒 Sécurité — Ce lien contient votre token GitHub et, si elle est activée, la clé d'équipe. Il est placé après le « # » de l'adresse : il n'est jamais envoyé au serveur. Partagez-le uniquement avec des personnes de confiance via un canal privé (SMS, WhatsApp, email pro). Ne le postez jamais publiquement.
🔗 Lien de configuration automatique
Envoyez ce lien à vos collègues. En cliquant dessus, la synchronisation GitHub se configure automatiquement sur leur appareil.
